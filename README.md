## ⚙️ How It Works

This tool utilizes **Hash Interception**. 

- 🔒 **It does NOT hack the host server.**
- 👁️ It reads the **unencrypted initialization hash** (the "Round Hash") generated by the client *prior* to execution.
- 🧠 By parsing this hash against known cryptographic seed logic, the tool accurately maps a **5x5 execution grid** before the client commits the transaction.
